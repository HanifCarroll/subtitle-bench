# Subtitle production process

Produce useful Turkish and English subtitles for normal viewing and Turkish language learning. This file is the authoritative production sequence. [WORKBENCH.md](docs/guides/WORKBENCH.md) documents commands; [DEVELOPMENT-AGENT-PROMPT.md](docs/guides/DEVELOPMENT-AGENT-PROMPT.md) is the reusable agent entry. Qualification is separate and remains paused; this process update does not authorize a held-out run, recognizer survey, or full-episode comparison.

Use a **local-first hybrid policy**. Prefer existing local tools when they provide useful results with reasonable effort; use authorized hosted tools when they materially improve recovery or save time. The completed local-only capability comparison was an experiment, not a permanent restriction. Preserve its findings, environments, and caches; do not reopen that comparison or add tools by default.

## Production order

1. **Initial Turkish transcription.** Default to `whisper-turbo`: local large-v3-turbo, one fresh CLI process per five-minute core, five-second overlap, no VAD. Record video identity and reuse independently generated drafts with matching receipts. The `gemini-five-minute` profile remains available when explicitly selected within authorized scope: Gemini 3.8 Flash, overlapping five-minute cores, five-second overlap, 32,768 output tokens, independent requests. Do not automatically produce a second full-episode transcript. Keep settings, raw outputs, usage, and seam evidence outside Git.
2. **Turkish repair and speech timing.** Audit possible omissions, repetition, chunk seams, and poor boundaries. Review accepted wording as well as flagged lines in coherent dialogue sections. Use `source-review.py` decisions and source-only workbench bundles. Resolve duplicated or boundary-crossing utterances from both raw clip alternatives and original-audio evidence; midpoint ownership is only provisional assembly. Align corrected Turkish with `align-turkish.py VIDEO SOURCE.tr.srt ALIGNMENT` before English exists. Batch source edits and alignment; validate affected text/timing after edits and run comprehensive checks at meaningful source and final checkpoints. English refresh and rendering do not belong in each initial source-repair loop.
3. **Turkish ready for translation.** Connect each current source/long-gap question to its saved decision before recording readiness; a summary saying coverage is complete does not resolve a contradictory queue. Save a small source-hash-bound `source-review.py ready` checkpoint after substantive source work is complete: coverage assessed, known material recognition defects repaired, speech timing usable, and ordinary dialogue reviewed. Supported alternatives and non-material warnings are acceptable; unanimous model agreement is unnecessary. A frozen snapshot, completed audit, exhausted allowance, or ordinary dialogue awaiting investigation is incomplete source work. Report it as incomplete and stop before bulk English. A genuinely unrecoverable span can have an honest timed caption after sufficient evidence; an indistinct-speech caption never substitutes for unfinished investigation.
4. **Bulk English generation.** The provisional default is a DeepSeek Flash draft via `translate-subtitles.py`, then agent review and correction. Direct agent translation via `agent-translate.py` remains available when provider calls are unapproved or unavailable, with the same final contextual check. Both use the same source context and terminology. DeepSeek uses contextual, conservatively token-bounded batches, up to four concurrent requests, adequate output capacity, exact source IDs, raw responses, and saved usage. A single coordinator serializes resumable checkpoint writes. Prompt and generation settings are part of cache identity. Complete validated coverage is required before export. Provider output retains provider authorship and never implies semantic approval.
5. **Contextual English review.** Review every English unit against current Turkish and adjacent dialogue, including apparently clean lines. Check negation, actor, referent, concrete objects, instructions, idioms, jokes, and additions. Correct English in the existing checkpoint and re-export; do not change Turkish just to permit an English correction. `semantic-review.py` records source-linked review independently of draft provenance. A late genuine source error reopens only its affected interval and English context; this is the exception to the normal source-first sequence. Preserve source links while allowing readable English grouping and line breaks; recognition segments are not final display cues.
6. **Final layout, export, and playback checks.** Keep alignment, layout, export, and rendering local. After wording review, finish alignment, separate display layouts, whole-candidate consistency checks, and sampled libass rendering. Use the existing dry release report; structural tests and review receipts do not establish every word's accuracy. Preserve originals and installed sidecars. Installation requires authorization, validated paired tracks, backups, verified installed hashes, and rollback on failure; native playback must be observed separately. No installation is needed for development translation comparisons.

## Choose evidence for the question

Register applicable saved independent receipts in the current source case's `saved_evidence` list (path, SHA-256, model for SRT, and applicable original-video start/end milliseconds). Scene inspection and bundles show those observations alongside the candidate. Saved focused proposals enter the existing source queue; saved words wholly inside subtitle gaps also enter it. Decide explicitly whether a contradiction is a recognition artifact, a supported alternative, or a material unresolved question. A focused rejection needs a named resolution; do not bury it in a list of retained cue IDs. Readiness checks that same case and its current decisions. New evidence invalidates an affected approval even when subtitle bytes are unchanged. These checks enforce review state, not linguistic correctness.

For English wordplay, identify the ordinary meaning and the next speaker's misunderstanding. Preserve both in natural English; a literal pun that removes the instruction is a material error. Do not replace a sound idiomatic draft merely to repeat the source's mistaken word literally.

- Disputed word or reply: focused existing Whisper/Qwen recognition with surrounding original audio. Keep Qwen inputs within 10–30 seconds and treat generated-token exhaustion as incomplete evidence. Optional 8-bit Qwen retains its observed loop robustness at modest extra memory, without an established word-accuracy gain.
- Speech activity or boundaries: Silero or targeted FireRed observations plus appropriate audio evidence. FireRed routes speech/music/singing questions; event labels, empty recognition, or absent VAD do not establish exact words or silence.
- Masking by music: optional existing Demucs separation, retaining the original mix, target, and residual. Compare relevant acoustic views with matching recognition settings.
- Speaker, object, action, referent, setting, or visible text: scene overview and timestamped frames before, during, and after the cue; record cue IDs, frame times, and observations. Frames cannot establish spoken words.
- Substantive question unresolved after an appropriate local attempt, or local work demonstrably inefficient: targeted hosted audio review within approved scope, reusing current Gemini review/binding and its budget accounting. Do not exhaust every local option before escalating. Repeating unchanged or unproductive local attempts is not progress.
- Broadly corrupted scene: consider reconstructing its Turkish with Gemini instead of patching many individual cues. Use bounded original-audio scene clips, an independent observation before candidate comparison, and the existing source-decision route. Review coverage and seams, preserve unsupported wording as uncertainty, and align accepted Turkish locally. Scene reconstruction does not imply a second full-episode transcript.

Do not require every tool for every scene. Recognition, forced alignment, model agreement, and references are evidence, not proof. Record whether the agent actually heard audio; transcripts and images alone are not listening. The agent performs text review directly; local speech recognition may supply audio evidence. Provider translation is an explicitly supported alternative.

## Small English-path comparison

Use one settled 10–15-minute section with ordinary dialogue and contextual expressions; settle only that section if necessary. Freeze Turkish and identical context/terminology first. Save independent A and B drafts before inspecting an English OpenSubtitles reference. Review both to the same practical standard, accepting equivalent translations and distinguishing reference defects. Record generation elapsed time, review/correction elapsed time, substantive errors repaired, total time to reviewed English, usage, and estimated cost. Choose the faster path only when reviewed quality is comparable; report an inconclusive result without starting another broad experiment.

The [2026-10-01 section comparison](docs/reports/ENGLISH-PATH-COMPARISON-2026-10-01.md) provisionally selects DeepSeek Flash drafting followed by agent review and correction. Reviewed quality was comparable and observed time to reviewed English was shorter. The raw provider draft needed meaning repairs; it must not bypass review. This is one development section, reviewed by the same agent, with wall-clock tool/context overhead, not an unseen-episode qualification or a general speed guarantee. Direct agent translation remains available when provider calls are unapproved or unavailable.

## Resources and authorization

Keep episode media, references, model output, credentials, cases, and backups outside Git. [SETUP.md](docs/guides/SETUP.md) records local environments. Before spending or uploading, check existing episode authorization and the conservative remaining allowance. If it does not cover the necessary work, request **one consolidated episode allowance for targeted audio recovery, including scene reconstruction, and English generation**. Record the video/hash, providers/models, purposes, call/audio/output limits, and total spending cap with the private run. Allocate provider caps within that total and account for prior attempts, repeats, and reserved work using existing usage receipts. Choose scenes within the approved scope without separate per-scene approval; stop before exceeding its limits. An audio-only permission does not cover English generation. Reuse receipts before spending again. Installation remains separately authorized. This document grants no paid permission or permission to start another episode.

Historical strategy decisions and qualification results remain in [history/production-process-before-2026-10-01.md](history/production-process-before-2026-10-01.md), [dated reports](docs/reports/README.md), and [qualification/PROTOCOL.md](qualification/PROTOCOL.md). They do not prescribe the current production order.
