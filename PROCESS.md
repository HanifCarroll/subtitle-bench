# Subtitle production process

Produce useful Turkish and English subtitles for normal viewing and Turkish language learning. This file is the authoritative production sequence. [WORKBENCH.md](docs/guides/WORKBENCH.md) documents commands; [DEVELOPMENT-AGENT-PROMPT.md](docs/guides/DEVELOPMENT-AGENT-PROMPT.md) is the reusable agent entry. Qualification is separate and remains paused; this process update does not authorize a held-out run, recognizer survey, or full-episode comparison.

## Production order

1. **Initial Turkish transcription.** Record video identity and choose one primary profile: `whisper-turbo` (local large-v3-turbo, one fresh CLI process per five-minute core, five-second overlap, no VAD) or `gemini-five-minute` (Gemini 3.8 Flash, overlapping five-minute cores, five-second overlap, 32,768 output tokens, independent requests). Reuse independently generated drafts and matching receipts. Do not run both full transcriptions by default. The Gemini profile uses the tested chunked route, not the historical single-request full-audio observation. Keep settings, raw outputs, usage, and seam evidence outside Git.
2. **Turkish repair and speech timing.** Audit possible omissions, repetition, chunk seams, and poor boundaries. Review accepted wording as well as flagged lines in coherent dialogue sections. Use `source-review.py` decisions and source-only workbench bundles. Resolve duplicated or boundary-crossing utterances from both raw clip alternatives and original-audio evidence; midpoint ownership is only provisional assembly. Align corrected Turkish with `align-turkish.py VIDEO SOURCE.tr.srt ALIGNMENT` before English exists. Batch source edits and alignment; validate affected text/timing after edits and run comprehensive checks at meaningful source and final checkpoints. English refresh and rendering do not belong in each initial source-repair loop.
3. **Turkish ready for translation.** Save a small source-hash-bound `source-review.py ready` checkpoint after substantive source work is complete: coverage assessed, known material recognition defects repaired, speech timing usable, and ordinary dialogue reviewed. Supported alternatives and non-material warnings are acceptable; unanimous model agreement is unnecessary. A frozen snapshot, completed audit, exhausted allowance, or ordinary dialogue awaiting investigation is incomplete source work. Report it as incomplete and stop before bulk English. A genuinely unrecoverable span can have an honest timed caption after sufficient evidence; an indistinct-speech caption never substitutes for unfinished investigation.
4. **Bulk English generation.** Keep two paths: A, a DeepSeek Flash draft via `translate-subtitles.py`, then agent review and correction; B, direct agent translation via `agent-translate.py`, then a final contextual check. Both use the same source context and terminology. DeepSeek uses contextual, conservatively token-bounded batches, up to four concurrent requests, adequate output capacity, exact source IDs, raw responses, and saved usage. A single coordinator serializes resumable checkpoint writes. Prompt and generation settings are part of cache identity. Complete validated coverage is required before export. Provider output retains provider authorship and never implies semantic approval.
5. **Contextual English review.** Review every English unit against current Turkish and adjacent dialogue, including apparently clean lines. Check negation, actor, referent, concrete objects, instructions, idioms, jokes, and additions. Correct English in the existing checkpoint and re-export; do not change Turkish just to permit an English correction. `semantic-review.py` records source-linked review independently of draft provenance. A late genuine source error reopens only its affected interval and English context; this is the exception to the normal source-first sequence. Preserve source links while allowing readable English grouping and line breaks; recognition segments are not final display cues.
6. **Final layout, export, and playback checks.** After wording review, finish alignment, separate display layouts, whole-candidate consistency checks, and sampled libass rendering. Use the existing dry release report; structural tests and review receipts do not establish every word's accuracy. Preserve originals and installed sidecars. Installation requires authorization, validated paired tracks, backups, verified installed hashes, and rollback on failure; native playback must be observed separately. No installation is needed for development translation comparisons.

## Choose evidence for the question

- Disputed word or reply: focused local recognition with surrounding original audio.
- Speech activity or boundaries: voice detection plus appropriate audio evidence. Empty recognition or absent VAD does not establish silence.
- Masking by music: optional separation, retaining the original mix.
- Speaker, object, action, referent, setting, or visible text: scene overview and timestamped frames before, during, and after the cue; record cue IDs, frame times, and observations. Frames cannot establish spoken words.
- Local evidence inadequate or demonstrably inefficient: authorized hosted audio review, reusing current Gemini review/binding and its budget accounting. Do not repeatedly run ineffective local checks to avoid a small authorized hosted call.

Do not require every tool for every scene. Recognition, forced alignment, model agreement, and references are evidence, not proof. Record whether the agent actually heard audio; transcripts and images alone are not listening. The agent performs text review directly; local speech recognition may supply audio evidence. Provider translation is an explicitly supported alternative.

## Small English-path comparison

Use one settled 10–15-minute section with ordinary dialogue and contextual expressions; settle only that section if necessary. Freeze Turkish and identical context/terminology first. Save independent A and B drafts before inspecting an English OpenSubtitles reference. Review both to the same practical standard, accepting equivalent translations and distinguishing reference defects. Record generation elapsed time, review/correction elapsed time, substantive errors repaired, total time to reviewed English, usage, and estimated cost. Choose the faster path only when reviewed quality is comparable; report an inconclusive result without starting another broad experiment.

The [2026-10-01 section comparison](docs/reports/ENGLISH-PATH-COMPARISON-2026-10-01.md) provisionally selects DeepSeek Flash drafting followed by agent review and correction. Reviewed quality was comparable and observed time to reviewed English was shorter. The raw provider draft needed meaning repairs; it must not bypass review. This is one development section, reviewed by the same agent, with wall-clock tool/context overhead, not an unseen-episode qualification or a general speed guarantee. Direct agent translation remains available when provider calls are unapproved or unavailable.

## Resources and authorization

Keep episode media, references, model output, credentials, cases, and backups outside Git. [SETUP.md](docs/guides/SETUP.md) records local environments. Provider calls, audio uploads, and installed-file changes need applicable user authorization; prior episode audio permission does not authorize new translation work. Save applicable scope and cost limits with the private run. Reuse receipts before spending again. This document grants no paid permission.
