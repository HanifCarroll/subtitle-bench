## What the first runs show

**007:** No good source subtitle was supplied. The source draft repeats an apparent credit label during the opening. In the disputed 28,000–57,980 ms interval, full and focused large-v3 returned the label while the full Qwen window returned a different spoken sentence. The agent saved original clips and an unresolved decision, then stopped because audio-capable independent review was outside the no-provider authorization. Ten Qwen windows were questionable repetitions and one was empty. No content repair was applied. A separate **development** test after the first run found zero Silero speech segments in that 34-second clip, while both 15-second Qwen retries repeated `Evet`; this did not establish a trusted answer. The case remains a video-only regression, not a qualified episode.

**021:** The supplied Turkish source had only 101 matching cues with anchors in two cut regions, so the agent rejected it and used the video ASR draft. Post-run inspection found the Turkish and English input files each repeat one Trabzon line in 1,005 of 1,540 cues; rendering made the late English corruption visible. The agent's first focused bundle used a full transcription manifest where the optional flag expected a focused-window manifest. This is a recoverable tool-use failure. In a separate **development** continuation, the bundle succeeded without that optional flag. The first 0–30-second source dispute still remained: large-v3 returned a generic closing phrase, Qwen returned an empty window, and the local receipt correctly refused to certify it. No source or translation repair was applied. The first-run partial remains in the denominator.

**077:** The user paused the campaign while this fresh run was active. The agent preserved its current inputs and caches at a safe boundary. The proposed Turkish reference had 312 agreeing distinctive anchors among 324 matches across four cut regions, with 135 ms anchor spread and a 100 ms offset; this supports cut timing only. Qwen returned 150 complete, nine questionable, and three empty windows, yielding 24 review questions. The agent had not reached a source decision or English production. This case is an **interrupted attempt with no tested completion outcome**, not a failed or successful episode. The pause is a user direction, not a request for a routine content decision.

The local receipt path has been exercised on an ordinary Episode 64 development interval, but these held-out first runs did not exercise it to a resolved repair. Its refusal on an empty Qwen result is a provenance safeguard. The unresolved words are a capability and permission gap, not a passed quality gate. Source transcription and full-window comparison run on real unseen media; autonomous subtitle completion has not yet been demonstrated. The campaign is paused pending a representative-interval recovery demonstration; no further held-out episode should be started under this freeze.

No independent bilingual annotation is available. Therefore omitted dialogue, material English meaning errors, wrong changes to initially correct cues, and timing error rates are **unmeasured**. E007 and E021 applied no content repairs, so an incorrect-repair rate from them would be meaningless. The frozen five-window, 15-minute-per-episode evaluation scope is in `evaluation-windows.json`. Local CPU/GPU time, electricity, and agent work are not monetized; the runs made no provider calls or uploads and incurred no provider charge. No installed sidecars were changed.

Evidence for each case: `run.json`, `events.jsonl`, completed transcription receipts, `audio-check.json`, reference report where supplied, and dry release/render reports where present. A structurally passing render or audio-window completion is not a trusted accuracy measurement.
