## Hard dependency visible in the current code

`scripts/source-review.py`'s `review_result_blockers` requires two saved `audio_capable_model` stages, independent observation and comparison, for every source decision it validates. `scripts/subtitle-workbench.py` applies that validator to current source and independent-ASR questions before release. The local Whisper and Qwen recognition commands produce transcripts, but the repository has no executable local two-stage audio comparison route that emits this receipt. The existing live generator is Gemini and requires separate authorization. Thus a source issue can remain release-blocking even when the agent has sufficient local evidence to repair it, and the no-provider frozen qualification may not be able to finish. This is a **release-path dependency**, not proof that the dialogue itself is unrecoverable. The held-out runs will report whether it prevents completion; they must not fabricate model stages.

The same review loop authors Turkish repairs, English translations, semantic decisions, and many timing decisions. Its internal judgments cannot certify accuracy independently. Qualification therefore keeps established reference answers, provisional ASR/model proposals, release-gate outcomes, and independent bilingual annotations separate. The preselected version 1 evaluation windows are in `evaluation-windows-v1.json`.
