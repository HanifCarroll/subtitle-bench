# Historical subtitle experiments

These scripts and notes are snapshots of earlier episode-specific work. They are kept for traceability and comparison; the supported workflow is in the parent directory. Some scripts assume the original local Movies workspace and are not part of the tested workbench entry point.

Paths in the historical notes under `pilots/` refer to private research evidence that is not published here because it includes episode media, subtitle content, or large model outputs. Shareable development results are indexed in [docs/reports](../docs/reports/README.md). The OpenSubtitles status note is dated September 28, 2026; use the local archive manifest for current counts.
