# E023 chunking comparison: raw transcription screen

Recorded 2026-10-01. Five-minute Gemini chunks restored whole-episode coverage after the single-request route stopped near 27 minutes. Isolated five-minute Whisper clips reduced reference disagreement relative to the earlier clip configuration. Chunked Scribe was incomplete because the account ran out of credit. **This screen did not settle Turkish, translate English, or qualify a production process.** See the later [downstream comparison](E023-DOWNSTREAM-COMPARISON-2026-10-01.md).

## Configuration and comparability

E023 lasts 82m29.621s; extracted audio ends 21ms earlier. Seventeen 300-second cores with five-second padding require 5,109.6 recognition seconds. The earlier Whisper run used 33 isolated 150-second cores with two-second padding; it was already chunked, not a whole-context baseline.

The older Gemini MP3 request allowed 65,536 output tokens. Its provider status was incomplete, despite the older adapter labeling the parsed output complete. Output plus thought usage reached 65,532/65,536 and text stopped near 27:16. Token exhaustion is strongly suggested; the provider did not explicitly report that cause. The new configuration used independent padded WAV clips, 32,768 output capacity per request and two workers. All 17 completed.

The old Scribe single upload internally segmented the audio into four sections longer than eight minutes; one upload was not uninterrupted full-context recognition.

## Invalid first Whisper run and material findings

An initial batch sent all 17 Whisper clips through one process. Clip 001 differed from two identical standalone runs, and the 60–65-minute clip repeated a stock phrase 116 times. That run took 371.6s with 34.2% disagreement and was excluded. The corrected isolated run reused frozen audio/model settings after the coordinator had opened references; it was not fully blind.

Whisper still hallucinated over opening music, repeated a short passage near 11 minutes, and had suspected name/negation errors near 31:15 and 60:55. Gemini's chunking primarily restored coverage, not demonstrated word accuracy. A suspected object error near five minutes was not independently listened to; its conditional near 12:30 was better supported. Scribe's missing calls returned HTTP 401 quota errors; a 160-second fallback also reported zero credits. Native timing did not resolve the suspected final-name error.

## Usage and operations

There were 35 model attempts: 17 Gemini, 17 Scribe and one Scribe fallback, totaling 10,379.2 processed audio seconds and 6,494 prompt bytes. The approved ceilings were 50 calls, 12,699.6 seconds, 100KB of prompts and US$5; conservative reservation was US$2.558.

Gemini returned 129,083 input, 47,146 output and 43,513 thought tokens, estimated at US$0.437. Successful Scribe audio totaled 2,939.6s, estimated at US$0.180. Combined estimate was about US$0.616, without an invoice. All 17 Gemini files reported deletion. Of ten saved Scribe results, three reported deletion and seven returned HTTP 404, leaving deletion unverified. Quota-failed calls and the fallback produced no saved transcript. Seventeen preliminary import reservations were voided before any upload/request.

No Turkish recovery, English generation, full timing/render review, native playback or installation was performed in this screen. The [current process](../../PROCESS.md) supports the tested Whisper/Gemini initial profiles and handles seams as review evidence, not automatic transcript acceptance.
