# Subtitle pipeline

[PROCESS.md](../../PROCESS.md) is the authoritative production sequence:

Turkish transcription → Turkish repair and speech timing → Turkish ready → bulk English → contextual English review → final layout, export, and playback checks.

Use [DEVELOPMENT-AGENT-PROMPT.md](DEVELOPMENT-AGENT-PROMPT.md) to begin or resume production and [WORKBENCH.md](WORKBENCH.md) for existing tool commands. Choose one initial recognizer, `whisper-turbo` or `gemini-five-minute`. Reuse independent drafts and evidence. Complete substantive Turkish work before either DeepSeek Flash or direct-agent English generation. Provider drafts need agent review; English-only corrections persist in the existing checkpoint.

Earlier source-first, per-scene repair/render, and recognizer experiments are historical records in dated reports and [history](../../history/README.md). They do not override the current process. Qualification remains separate and paused. No full-episode experiment, provider request, or installation is authorized by this document.
